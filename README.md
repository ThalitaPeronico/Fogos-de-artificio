# Fogos-de-artificio
Animação simples de fogos de artifício em java.

## Como executar o projeto


### 1. Clonar o repositório

Abra o terminal e execute:

```bash
git clone https://github.com/ThalitaPeronico/Fogos-de-artificio.git
```


### 2. Entrar na pasta do projeto

```bash
cd Fogos-de-artificio

```

### 4. Executar o programa

Execute:

```bash
java -cp class Main
```

### 5. Visualizar a animação

Após executar o programa, uma janela será aberta. Clique dentro da janela para iniciar a animação dos fogos de artifício.
